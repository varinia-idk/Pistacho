# Assets originales

`branding/pistacho.svg` es el icono vectorial original del juego.
Los personajes, cajas, minas, bombas, enemigos, cetro y montaña se dibujan con CanvasItem en los scripts de presentación. Los sonidos se sintetizan en memoria en `sound_bank.gd`.
No se requieren paquetes gráficos, fuentes ni sonidos externos.
